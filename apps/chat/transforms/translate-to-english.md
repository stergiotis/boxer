---
title: Translate to English
summary: Translate the text in the markdown editor to English, keeping the markdown structure.
icon: "🌐"
scope: selection
---

Translate the prose into clear, natural English. Preserve the markdown
structure exactly: heading levels, list markers, emphasis, links (translate
the label, never the URL), tables and frontmatter keys stay as they are, and
code blocks are not translated at all. If the text is already in English,
say so and propose nothing.
