# Desktop keys

These keys belong to the desktop, not to the window that has focus: the
window never sees them. They all use Alt. A key that differs between
keyboards is listed under each spelling. The table is generated from the
one the desktop matches keys on.

| Keys | What it does |
| --- | --- |
| Alt+J | Focus the next window: in the layout's order when tiled, in the stacking when floating. |
| Alt+K | Focus the previous window, in the same order. |
| Alt+H, Alt+Left | Focus the nearest window to the left. |
| Alt+L, Alt+Right | Focus the nearest window to the right. |
| Alt+Up | Focus the nearest window above. |
| Alt+Down | Focus the nearest window below. |
| Alt+Shift+J | Swap the active window with the next one in the layout (tiled). |
| Alt+Shift+K | Swap the active window with the previous one in the layout (tiled). |
| Alt+Shift+Left | Snap the active window to the left half of the work area; again for the quarter (floating). |
| Alt+Shift+Right | Snap the active window to the right half; again for the quarter (floating). |
| Alt+Shift+Up | Snap the active window to the top half; again for the quarter (floating). |
| Alt+Shift+Down | Snap the active window to the bottom half; again for the quarter (floating). |
| Alt+Enter | Make the active window the main one (tiled). |
| Alt+Space | Step to the next tiled layout; on a floating desktop, switch to tiled. |
| Alt+Shift+Space | Take the active window out of the layout, or put it back (tiled). |
| Alt+F | Show only the active window (tiled), or maximise it (floating). |
| Alt+Equals | Widen the main area. |
| Alt+Minus | Narrow the main area. |
| Alt+Plus, Alt+Shift+Plus, Alt+Shift+Equals | Put one more window in the main area. |
| Alt+Shift+Minus | Put one fewer window in the main area. |
| Alt+Tab | Focus the window that was active before this one. |
