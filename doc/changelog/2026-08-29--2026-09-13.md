## The window in brief

This section carries no commit hashes and no links; everything it claims is
cited in the body below.

No tag was cut, so nothing here has shipped under a version — the whole window
is unreleased work past v0.0.22.

Three through-lines. The largest is a graph widget written in Go on the painter
lane: it starts as a sibling of the egui_graphs-backed binding with that
binding's feature set, then grows over two weeks into auras, a pick grid, an

exactly-one-membership becomes a writable schema statement, the canonical form

names get SQL views that read them apart.

Beside those: durable background work as facts, two storage contracts for
pushout, markdown documents as queryable facts, the launcher as an app, and
mimalloc retired so a build can reproduce.

The window carries no marked breaking change but several unmarked ones — a
storage interface that gained methods, a retired build tag, an exported error
rename — and an ADR number collision that moved a decision from 0225 to 0227
after citations were written against it. Nine of the seventeen new ADRs are
still marked proposed although their work has shipped.

## CS013: values move off error messages onto eb fields (ADR-0011)

[ADR-0011](../adr/0011-codelint.md) listed "always-`%w` for error args" as a
phase-2 rule needing `go/types`; `ca1d0689` is it. The premise
is that an error message used to do two jobs: a `%q` or `%d` flattens a value
into prose, where the CBOR payload, the zerolog field set and any query over
persisted errors see one opaque string. Detection is by type rather than by
receiver spelling, so a builder held in a variable is covered, and the format is
resolved through the type checker's constant folding. Four shapes are
deliberately not flagged, each with its reason recorded on the rule: a format
with no directives, two or more `%w`, a non-constant format, and `eh` itself.

The rule then learned to explain itself — naming fields from types and saying
why it declined (`1ea5f9f9`), and offering the mechanical rewrite it can make
(`1527a77a`) — and the driver learned to skip test-support packages for every
rule (`2674e079`), since a conformance suite's assertion code lives in ordinary
files and its findings are not defects. `4bce7762` adds `ebtest`, which reads an
`eb` payload back in a test, so a moved value can be asserted on.

The sweep is the rest: twenty-five `refactor` commits over two days,
package by package — coverage (`b7612355`), recordstore's generator
(`f6adcd64`), ecdfbands (`ee8d8ea3`), swisstopo (`54869aae`), adhocdata
(`6573c615`), pushout (`d0048214`), chstore (`b0808c09`), queryrunfacts and
sysmreplay (`50ef9fd3`), marshallreflect (`b7ed7960`), designsystem/colors
(`846280c7`), capmapfacts (`d63f9cc2`), ladingsql (`9a33816c`), wavfile
(`a8eac718`), imzero2 (`2b5ad390`), keelson's runtime (`a5d107b1`), the
clickhouse DSL and leeway (`b0bb6c39`), extbin, gov, gloss and keelson's data
layer (`cc1cd798`), pushout, stats and the app commands (`4b5fc917`), sqlapplet
and the non-GUI apps (`1a5166fd`), play and tally (`fee2f58c`) — with two
mechanical passes over the tail (`14bbbae9`, `e745c9fb`) until `public/` reached
zero findings (`a27dddb5`). Two commits are about what the rule could not
decide for itself: `99493050` names error fields from their types where the
variable could not, and `ab4121e3` puts constants back in the sentence where
they fill a grammatical slot rather than a data slot — the distinction
`9774b93b` then fixed in goplan.

`e5079871` promotes the rule to error severity on ADR-0011's staging policy
("only when the residual count is zero"), down from 1116 findings when it
shipped. `a5d66841` records what CS013 enforces and the four exceptions that
survived the sweep — a message crossing a text-only boundary, a directive in a
grammatical slot, a remedy the reader copies verbatim, and a message another
component string-matches — each carrying its reason on the line.

## leeway: single-membership declaration (ADR-0213), the canonical form and wire, fixed-width text

[ADR-0213](../adr/0213-leeway-single-membership-declaration.md) (accepted,
`06fd9e13`) makes the exactly-one-membership property a writable schema
statement rather than something a reader must detect (`7ffa92cb`). Per-channel
section use-aspects (`AddSectionSingleMembership`) let the DDL omit the
`<role>card` lane, the generated DML enforces the arity at write time, and
every reader takes lwextract's fast form on the strength of the declaration —
the read-back generator (closing invariant I5, previously recorded as "detection
is an open problem"), the `LW_GET` authoring surface, the generated read-access
packs, and streamreadaccess. The declaration is representation and never
content: canonform digests are pinned equal across a declared/undeclared twin
pair, and "declared single" does not join the canonwire wire, slot key or accept
mask. Undeclared schemas regenerate byte-identically. Fixtures sit in
`leeway/test/singledecl`, with a striple pinning the facts11′-shaped
four-channel section (`e7b68863`).

**canonform** gained refusals for undefined inputs, a declarative `PlainsMask`
with a canonical string form for pinning, and `Encoder.FormPin()` rendering the
digest's non-record domain, beside the ADR-0201 M1 rapid suite (`4a4a6598`);
`aa147d79` adds the optional `PinnableI` classifier capability that `FormPin` is
the first consumer of. **canonwire** gained a generator fuzz that type-checks
the generated readaccess, DML and canonwire sources as one package against the
real dependency graph, plus a channeltable golden covering the five membership
channels the other tables leave out (`dbda61dc`) — it caught the emissions
`f12496a9` fixed, where a `Parameterized`/`Parametrized` spelling split and two
nonexistent Arrow builders meant generated code did not compile for every table
the generators accept. `b592c28a` is the adversarial-review pass over the
runtime, cited under breaking changes above.

**Fixed-width text (`sxN`) generates** (`dfd71d29`): both fixed-width lanes map
to `FixedSizeBinary`, generated appends go through `runtime.AppendFixedText`
(exactly-width verbatim, shorter zero-padded per ClickHouse INSERT semantics,
longer refused onto `CheckErrors` rather than panicking inside the Arrow
builder), and the generated decoder reads with `ReadTextStringFixed(N)`, which
refuses any other length. Goldens and fixed-width pins in `6947dea8`; the `sx`
edges in streamreadaccess and marshall in `315a823b`.

`c709a5e0` folds three spellings into the convention that owns them —
`NameLayoutE` exposes field positions and the component names become exported
constants, `PlainSectionName` moves out of lwsql, `DefaultSeparator` moves to
ddl — which is what the schema-decode views below stand on.

## leeway: schema-decode views (ADR-0226)

[ADR-0226](../adr/0226-leeway-schema-decode-views.md) (proposed in
`93ebc342`, accepted at `8d884d15`) adds `leeway.columns`, `leeway.sections` and `leeway.tables` to the SQL read
surface (`274a786c`): one row per column of every non-system table with its
physical name read apart — layout, prefix, section, column, role, lane kind,
canonical type, the three aspect sets and their raw segments, row config,
co-section and streaming group — joined to `system.columns`' type, position and
compression figures, with two aggregates above it. Nothing is typed into the SQL
by hand: field positions come from the naming convention's layout accessor, the
transform tables from the enum rosters, and the aspect segments are handed to
chpack's `LW_ASPECT_NAMES_*` rather than re-rendered, which is what keeps this
from being the second implementation ADR-0170 §Q1 rejected.
`TestFieldPositionsMatchTheComposer` is the guard. `8d884d15` gives the views
their applet corpus — `bookleeway`, five chapters beside `bookcatalog` under
`TopicData` — and `83144206` puts them on the read-surface pages.

## pushout: machine-checked claims, storage capabilities (ADR-0220), batch verbs (ADR-0221)

`c1b490bf` turns four algebraic claims the engine had stated in prose —
commutativity, all-or-nothing `Apply`, idempotent double-apply, crash-safe
`Unrecord` — into tests, and two failed: an `AddEdge` between a tombstone and a
live node never dirtied the deleted component, and `Render` ordered conflict
branches by Tarjan SCC numbering, which follows adjacency insertion order, so
two replicas with identical graphs rendered differently. `8e413bfd` makes
"machine-checked" reproducible script by script, `b9f9b78e` fixes six assertions
the per-batch verification could not see, and `be46041a` says what the engine is
and cites the tests where a claim now has one.

[ADR-0220](../adr/0220-pushout-storage-capabilities-and-retention-mode.md)
(**proposed**) makes the store declare what it persists (`0d03d861`):
`StorageI` states `Snapshots`, `RetentionLedger`, `ReplaceApplied` and
`ExactEnvelopeBytes`, and the engine reads the declaration once at `Open`
instead of asserting on the store's type. The retention ledger carries purge
markers, so `Sweep` makes exactly one durable write and the snapshot is purely
an accelerator a store may disclaim honestly; `Options.Retention` (Hygiene,
None, Compliance) is validated at `Open` and `Repo.Guarantees` derives the
consumer-facing contract. `22452c85` carries purges into the crash-recovery
model with a counterfactual for a store without a carrier, and
[pushout-sweep-and-purge-durability](../explanation/pushout-sweep-and-purge-durability.md)
(`3943867c`, `62ed669c`) is the explanation.

[ADR-0221](../adr/0221-pushout-storage-batch-verbs-delta-ledger.md)
(**proposed**, `e69db6f0`, restated generically in `5ecf18ac`) is the batch
path. `83eb1dec` adds `ApplyEnvelopes`, an order-insensitive ingest verb —
ingesting a history one envelope at a time costs one graph clone per patch and
rejects anything whose dependency has not been applied, where the batch verb
dedupes, topologically sorts with a bytewise hash tiebreak so the log order is a
function of the set, reports unsatisfiable dependencies as pending, and runs the
transactional tail once. `765a24f0` pushes that down: `StorageI` gains
`PutEnvelopes` / `LoadEnvelopes`, `SaveRetention` becomes `UpdateRetention` over
a delta so every ledger write is the change rather than the set,
`exchange.AcceptorI` gains the batch verb, and the decoded-patch cache becomes
`repo/history.go` behind a stated contract. `f9bbb01d` adds conformance fixtures
for re-encoding stores. `0f672b7f` makes `Clone` copy without sorting.

## watchbill: durable work as facts (ADR-0223)

[ADR-0223](../adr/0223-watchbill-durable-work-on-facts.md) (accepted,
`9840cd42`, with a
[ClickHouse-primitives background page](../adr-background-work/watchbill-clickhouse-primitives.md))
puts background jobs in the facts store rather than a queue. M1 (`782556dd`) is
two generated record stores on store-owned tables in a Layout-named database:
one row per job rewritten in place, one row per transition appended, every
attribute its own section so a claim rewrites one array element and guards on
another. The claim, transitions, queue read, running-of predicates and expiry
are hand-written SQL over physical column names read out of the generated DDL at
init and pinned verbatim by tests; twenty-one memberships join the runtime
vocabulary at ordinals 74–94.

M2 (`c788555b`) is the worker: `StoreI` is the seam, every mutation a guarded
update whose read-back is the answer, with `SqlStore` over the generated stores
and `MemStore` as a test double with the same semantics. The worker polls or
wakes, claims, runs each job as a keelson task, honours a cancel within a poll,
sweeps rows held by runs with no heartbeat, retries under the row's policy and
expires finished rows. Building it found what the probe could not — a
heavyweight mutation lets two claims both win — so every update carries
`update_parallel_mode='sync'` and the expiry deletes as a lightweight update;
six hundred rounds with forced merges racing twenty claimants produced no
double. M3 and M5 (`de3c9362`) add the host's worker, the CLI group and
`keelson('watchbill')`, and `2e78d78c` the sqlapplet book: five chapters over
the two tables, so the book needs no external ClickHouse.

## graphview: a graph widget in Go (ADR-0224), navigation (ADR-0225), play's panel (ADR-0227)

[ADR-0224](../adr/0224-graphview-go-graph-widget-painter-lane.md) (accepted at
`ad5f0064`) is the largest arc of the window. `44971f75` lands the widget as a
sibling of the egui_graphs-backed Graph binding with the binding's feature
set — random, force-directed with and without centre gravity, and hierarchical
layouts, node drag, pan and anchored zoom, click and selection events, parallel
edges and self-loops, the one-shot fit latch, fast-forward and the settle
metric. Go owns topology and geometry; only paint commands cross the FFI. Two
departures from the crate are recorded in the ADR: the ideal edge length derives
from the canvas area rather than the screen, and random and hierarchical
placement are deterministic so the gallery capture is stable. The binding stays
until its downstream consumers have migrated.

## Hosted canvas rendering (ADR-0228) — a graph on a map

[ADR-0228](../adr/0228-hosted-canvas-rendering-and-graph-widget-sharing.md)
(proposed in `2130cdfa`, accepted at `afe47cd2`) asks what two graph widgets on the painter lane should
share, and its answer's second phase is a graph drawn over a slippy map
(`f1c3d6ed`). graphview gains `HostCanvas`, `HostClaim`, `HostedInput` and
`HostedPaint` — a render that paints into the canvas that is current and reads
its input from handles a host names, emitting no canvas, no sense region and no
background — and portolan gains `Map.Handles` and `Map.SetPointerVeto`. Hosting
is two calls because a host applies input at the top of its frame and offers its
paint slot at the bottom, so one call could only ever claim a gesture the host
had already acted on. The arbitration rule is one sentence — a gesture starting
on a node is the guest's, everything else the host's — and the host is told
rather than asked, so it needs a boolean and no knowledge of its guest. SD3 had
said `SetCamera`, `FitNow` and `FitNodes` would be refused; they are overruled
instead, since `HostedInput` reinstalls the host's transform every frame.

Phase 3 (`afe47cd2`, accepting the ADR) moves layeredgraph's hit-testing into
Go: hover and click had been reported by one `PaintSenseRegion` per node emitted
before the canvas so the regions won the hit test, and are now a Go-side pick
against the pointer the canvas's registers carry — the reasons ADR-0224 §SD3
gave for graphview, plus the fact that a widget needs it before a host can hand
it a canvas. The pick tests what `drawNode` drew, shape by shape, last match
wins, and the scan is deliberately linear for the tens-to-hundreds of nodes this
widget draws. One behaviour changed: a host with pan enabled now pans from a
drag starting on a node, where the node's region used to swallow it. The how-to
is [graph-on-a-map](../howto/graph-on-a-map.md) (`cb7780bc`); `1841874e` is the
portolan fix underneath it, where a faithful port of Leaflet's clip met an ear
clipper that is only defined for a simple polygon.

## Build: mimalloc retired (ADR-0215), the last build tag gone (ADR-0212)

[ADR-0215](../adr/0215-retire-mimalloc-reproducible-builds.md) (**proposed**;
cited here although its commit is a `build`) starts from a measurement nobody
had taken: two release builds of `rust/imzero2` five minutes apart differed in
94,543 bytes, and the cause was one string — mimalloc's `options.c` passes
`__DATE__, __TIME__` into a verbose message, so every binary carried a wall
clock, and `fast_alloc` was in the desktop default and every build script
(`b0f68db7`). So mimalloc goes entirely, which also finishes ADR-0205 M6 since
`libmimalloc-sys` was the last crate blocking a musl target. The rest was path
leakage, closed by two sourced files —
[rust-repro-env.sh](../../scripts/dev/rust-repro-env.sh) for the
`--remap-path-prefix` pair beside `--locked`, and
[go-build-env.sh](../../scripts/dev/go-build-env.sh) for tags, `-trimpath
-buildvcs=auto`, `CGO_ENABLED=0` and a pinned `GOTOOLCHAIN`. `2e9184b3` gates
reproducible builds of the Go host and the lean render head in CI, and
`6e5c7fe8` makes airgap source the same environment.

[ADR-0212](../adr/0212-split-pprof-http-listener.md) (accepted) retires the last
required build tag (`5963d704`). ADR-0199 SD2 had kept
`boxer_enable_profiling` because the enabled arm blank-imports
`net/http/pprof`; that reasoning was right about the side effect and wrong about
who pays. Measured: boxer's own binaries link `net/http` regardless and lose
under 0.3%, while a consumer-shaped module linking the profiling flags and
nothing else pulling `net/http` goes from 5,565,764 to 11,909,490 bytes and 126
to 238 packages. So the answer is a split rather than a choice between arms:
`profiling` keeps the file-based capture and imports no `net/*`,
`profiling/pprofhttp` owns the listener and serves a mux built from
`net/http/pprof`'s exported handlers rather than the default one. `./tags` is
now empty; `88eacb1a` and `4efa34cd` align the documents that said otherwise.
