## Breaking changes

Eight commits carry the `!` marker, against none in the previous window. Seven
of the eight are the leeway identity and read-surface work, which was
deliberately taken as one atomic window rather than a deprecation ladder.

| Commit | What breaks |
|---|---|
| `d376b608` | aspects v2: the segment codec flips, 33 zero-reader aspects are removed and 19 added; everything embedding an aspect segment moves in one commit |
| `80e91405` | every vocabulary claims its tag value through `identity/tagmint`; every membership id moves |
| `d7cadeb2` | a membership's ordinal is declared beside its name instead of counted at registration |
| `4c1c0bd2` | `stopa` becomes `leeway/namemint` |
| `14f677e1` | `chpack.Install`, `chpack.Version` and `LW_PACK_VERSION` are removed in favour of one `LW_SURFACE_VERSION` handshake |

## leeway: an authoring surface for the SQL read side (ADR-0181, ADR-0171)

[ADR-0181](../adr/0181-leeway-dql-authoring-surface.md) (accepted) is the
largest arc in the window. It starts from three normative contract documents
(`2846cf88`, M0) and then builds the surface those contracts describe:

- **Constructors.** `LwConstructExpand` and `LwShapeCheck` (`f0ab1b77`,
  SD2/SD5), the spec→name seam and an audit-query generator (`afd1127c`,
  SD6/SD5), `LW_SEL` for selection with mixed channels made readable
  (`f651bb1a`), and the membership id spelled without quotes (`69e75979`).
- **Extraction.** One builder for locate-and-extract (`b6cc18a4`, SD3) under
  the `LW_GET` family and `LwExtractExpand` (`32cc848e`, SD3).
- **DDL.** A skip-index derivation policy over `TableOptions` (`3c6c61fd`,
  SD4), `ddl compose` for durable `CREATE TABLE` from constructor-style specs
  (`554aa719`, SD6), and role / co-section group / streaming group extracted
  back out of physical names (`335125d2`).
- **Registration.** The pass joins the registry and constructor names appear in
  play's Vocabulary panel (`a6b60475`, SD7).

**SD8 — statement wrapping** was decided mid-arc as INSERT-only and
target-bound (`8d3dd974`, docs) and then implemented across four milestones:
the wrapper parses in both grammars while the pipeline entry refuses it
(`8e09ac79`, `9050c762`, M0), the pass pipeline carries it (`0a574507`, M1),
mints adopt a resolved INSERT target (`429bee40`) with a target-adopting
constructor factory in the standard set (`2a2df989`, M2), and the `SET`
parameter prelude rides the wrapper (`b74dad2d`), which M3 records as fully
implemented (`7a9bf9e0`, docs). play gained the write half of Run — gated,
formatless and summary-reported (`d4634249`) — and the `anchor` example a live
write-back demo (`3fcd123b`), with the mesh worked example beside it
(`022cefce`).

[ADR-0171](../adr/0171-leeway-sql-read-surface.md) (accepted, and marked
proposed in the previous entry) closed two of its own sub-decisions: one
version handshake for the whole surface (`14f677e1`, SD2) with a
`sqlsurface` CLI that installs, reports status, prints and drops undeclared
functions (`05f65faf`), and membership names made readable from SQL
(`4339b6a1`, SD4). SD3 and SD5 were deferred rather than built (`760f78a1`,
docs).

## leeway: identity and the mint layer (ADR-0183)

[ADR-0183](../adr/0183-leeway-component-consumer-simplification.md) (accepted)
began as a consumer-complexity inventory (`a5224f9f`, docs) and became the
window's identity overhaul. Its D0 rung is that durable values are declared in
source rather than derived from how the source happens to be arranged:

- `identity/tagmint` — tag values are claimed, not constructed (`486cdf38`);
  every vocabulary then claims one (`80e91405`). The commit message records
  what committing the assignment tables exposed: two vocabularies had both
  picked tag value 2, each with a comment explaining that it picked 2 to stay
  clear of the other.
- `leeway/namemint` (renamed from `stopa`, `4c1c0bd2`) takes a membership's
  ordinal beside its name (`d7cadeb2`), and every vocabulary commits its
  name-to-id table (`0f9d5fbc`). The reflect path can take its ids from the
  registry (`b5e5888b`).

The component-layer half: typed `Add` verbs now buffer, so two components can
share a section without routing through `Raw()` (`63c57665`, D4); a
`,unit` slot's multi-element value is refused instead of zero-filled
(`a003eafd`, D5 M0); one buffer owns the write frame's order and its invariants
(`52a31b90`), which `RowComposer` (`4ea57976`) and `chstore`'s one hand-rolled
section buffer (`cfd99978`) both adopt. A membership-id wrapper seam lets
components share sections under registry-stable ids (`dc7b43ce`).

## leeway: aspects v2 (ADR-0182)

[ADR-0182](../adr/0182-leeway-aspects-v2-codec-and-vocabulary.md) (accepted)
ran as a staged flip: the v2 segment codec landed inactive alongside v1
(`7ed34932`, M0), then the atomic window replaced it — codec flip, timeless

was removed outright beforehand (`be47b3b4`), on the grounds that it duplicated
Stevens' nominal scale.

## Facts-bound record stores (ADR-0105) and the sysmetrics tee (ADR-0184)

[ADR-0105](../adr/0105-keelson-adopts-generated-record-stores.md) (accepted)
built the three pieces its D-numbered plan called for: a recordstore executor
over `chclient` (`03cdff6c`, D1), facts-bound record-store generation
(`e5aa9d2d`, D2), and a generated store for app state (`8e447b8b`, D3a) that
`persist` adopts as its durable backend (`854dba1d`). Generated stores now bind
their table at run time and issue `EnsureTable` one statement per `Exec`
(`87e30e9a`), gained a seam for binding existing read-access scaffolding
(`b258a621`, taken up at `7aadf191`), and omit the DDL-execution surface when
externally provisioned (`308a7cbe`, `4e837395`). The persist store bakes the
runtime vocabulary's ids rather than declaration-order ones (`c353f2c8`).

[ADR-0184](../adr/0184-sysmetrics-persistence-tee.md) (accepted) is the first
adopter, and closes ADR-0090's P5. All six milestones ran on 2026-08-14: the
system-metrics vocabulary at tag-value base 32 (`666caafd`, SD4) and cpu/mem
component DTOs over `boxer.facts` (`1021cde6`, SD3); the generated metrics
store (`05ef9a05`); the tee itself (`bc03531e`) with `sysmetricsd --tee`
(`2cc2fa48`); psi, net, disk, battery and gpu memberships, DTOs and tee
(`73ef0a17`, `bbdef6bc`, `85e9db39`, M4); proc, proc-cmd and socket, with
command lines opt-in (`d2cd78c0`, `2a967c61`, `8461eb97`, M5); and the CPU
containment tree as an adjacency list, flattened and stored (`0cb83966`,
`34abce97`, M6).

## play: SQL-expression parameters (ADR-0187)

[ADR-0187](../adr/0187-play-sql-expression-parameters.md) (accepted) covers
what a ClickHouse parameter cannot carry — an expression — so the substitution
is client-side. The editor half came first: a SQL field for fragments,

(`43de637f`), substitution before the body ships (`f4902c9d`), two tiers for a
knob — its declaration, or the signal store (`9ec6153d`) — and the class
ceiling, where a substituted query is classified and an applet refuses one that
outgrows its class (`6adb8d9b`).

## sqleditor: completion (ADR-0190)

The window's last four days built an exact completion context for the SQL
editor. ADR-0190 (**proposed**) records the design; the file was not yet
committed at compilation, so this section cites the commits only.

- **`chtype`** — a ClickHouse type-string parser, because three sources hand
  the authoring surface a type as a string and nothing else (`2ea19691`,
  SD5/SD6), with a component's slot list read back off its `Projection`
  (`599ae7ad`).
- **`dsl/sqlvocab`** — argument domains declared beside the roster that
  declares the function, replacing six packages' separate display-spelling
  `Params` (`a45ba70b`, SD4).
- **`SiteAt`** — the caret's completion context from the lex tier, so it
  answers on a buffer that does not parse (`6d89a363`, SD2).
- **`sqlcomplete`** — the engine: member access, then the innermost known call
  frame, then the clause, with a reason recorded for every silence
  (`34657822`); and the sentinel parse, which repairs the statement
  deterministically and runs the tree on a worker (`881b0a5b`, SD3).
- **play** — a completion pane at the caret, a table rather than a popup, plus
  a tint that says the token resolves (`7c32be53`, SD8).
