# Go file / package naming baseline (ADR-0048).

# Each line below is a violation present on `main` at 2026-06-21 that
# pre-dates the naming spec. The scripts/ci/file-naming.sh --strict gate
# wired into scripts/ci/lint.sh only fails on NEW violations not in this
# list (and on baseline lines that no longer violate — keep this file
# in sync when you rename).
#
# Line format: <kind>:<path>
#   file:<path>              rule N1 (file basename must be snake_case lower)
#   generated-suffix:<path>  rule N2/N3 (a file carrying the generated-code
#                            header must end .out.go or .gen.go)
#   package:<dir>            rule N6 (package name must be lowercase, no _)
#   app-prefix:<path>        rule N7 (files under apps/<n>/ must start with <n>_)
#
# Removing a line here means the corresponding file or package has been
# renamed to conform. Do NOT add new entries here; fix the source instead.
#

# *.out.go, *.gen.go.
